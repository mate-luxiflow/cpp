📌 PASS BY VALUE vs PASS BY REFERENCE (43_pass_by_VALUE-REFERENCE.cc)
─────────────────────────────────────────────────────────────
// Pass by VALUE: creates a copy (original unchanged)
void func(int x) { x = 10; }  // original unchanged

// Pass by REFERENCE: uses original (&)
void swap(std::string &x, std::string &y) {
    std::string temp = x;
    x = y;
    y = temp;
}

📌 POINTERS (46_pointers.cc)
─────────────────────────────────────────────────────────────
// Pointer = variable that stores a memory address
// & = address-of operator
// * = dereference operator (access value at address)

std::string name = "Mate";
std::string *pName = &name;   // pName stores address of name
std::cout << *pName;          // prints "Mate" (dereference)

📌 RECURSION (50_recursion.cpp)
─────────────────────────────────────────────────────────────
// Function that calls itself
// Must have a base case to stop
int factorial(int n) {
    if (n <= 1) return 1;      // base case
    return n * factorial(n-1); // recursive call
}

└─────────────────────────────────────────────────────────────┘

⚠️ 1. Forgetting #include <string> when using std::string
⚠️ 2. Using = instead of == in conditionals (assignment vs comparison)
⚠️ 3. Off-by-one errors in loops (i <= size vs i < size)
⚠️ 4. Forgetting break in switch statements (fall-through)
⚠️ 5. Mixing up pass-by-value and pass-by-reference
⚠️ 6. Using uninitialized variables (they contain garbage values)
⚠️ 7. Forgetting to delete dynamically allocated memory (memory leak)
⚠️ 8. Dereferencing null or uninitialized pointers (crash)
⚠️ 9. Array index out of bounds (undefined behavior)
⚠️ 10. Integer division truncating (use double cast for decimals)
⚠️ 11. Using & instead of && or vice versa (bitwise vs logical)
⚠️ 12. Shadowing global variables with local ones (use :: to access global)
